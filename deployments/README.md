# Across Deployment Addresses

This is a legacy Hardhat deployment folder.

`legacy-addresses.json` is still kept here for older Hardhat deployments. The current source of truth for deployed contract addresses is [`broadcast/deployed-addresses.json`](../broadcast/deployed-addresses.json), which is generated by `yarn extract-addresses`.

`yarn extract-addresses` merges this file with the Foundry broadcast receipts, reading `legacy-addresses.json` first so that a broadcast receipt wins on conflict. Both therefore resolve through `getDeployedAddress()`.

Despite the name, this file is not strictly Hardhat-era: it is also where a new deployment is recorded when it cannot produce a usable broadcast receipt. `SpokePoolVerifier` and `AcrossEventEmitter` are the standing examples. Each is deployed from the initcode recorded in its `mainnet/<Name>.json` artifact rather than from `type(<Name>).creationCode`, because recompiling the source with the current toolchain changes the initcode and so the CREATE2 address, which would forfeit the single canonical address the contract holds on every chain. Forge cannot name a contract whose initcode matches no local artifact, so its receipt would record as `Unknown` — hence `legacy-addresses.json` is the only record of it, on every chain it is deployed to. Contracts built from current sources (SpokePool, MulticallHandler, SpokePoolPeriphery, ...) get real receipts and must not be added here.

For per-chain legacy Hardhat deployment artifacts, see the subdirectories in this folder. `yarn extract-addresses`
does not read them, so an address that lives only in a subdirectory is invisible to `getDeployedAddress()`; add it
to `legacy-addresses.json` as well.
